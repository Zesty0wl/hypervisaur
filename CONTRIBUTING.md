# Contributing to Hypervisaur

Thanks for your interest in Hypervisaur. Bug reports, ideas and pull requests are welcome.

## Reporting problems

Open an issue describing what happened and what you expected, with the version of Hypervisaur and macOS, your Mac's model, and the guest operating system. For Windows virtual machines, the end of `qemu.log` in the virtual machine's `.vbdata` folder often explains what went wrong.

Please report problems with Hypervisaur here rather than to VirtualBuddy, even when the code involved came from VirtualBuddy.

## Pull requests

- Keep each pull request to one change, and explain why it's needed.
- Match the style of the code around your change.
- Add or update tests where the change can be tested, and make sure the `VirtualCore` tests pass.
- Keep VirtualBuddy's module and type names, so that changes from VirtualBuddy can still be merged.

You're welcome to use AI tools, as long as you've read, understood and tested what you submit. Say in the pull request if you used them.

## Code of conduct

Everyone taking part in this project is expected to follow the [code of conduct](./CODE_OF_CONDUCT.md).
